# JLDN RPG Dice — Usage & Command Guide

> **Document:** `docs/usage.md`  
> **Author:** Jeff Langdon (JL Design Network)  

---

## 1. Installation

Install via Pulsar Package Manager (PPM):

```bash
ppm install rpg-dice
```

---

## 2. Command Palette Triggers (`cmd-shift-p` / `ctrl-shift-p`)

| Command | Action | Keybinding |
| :--- | :--- | :--- |
| `rpg-dice:roll` | Evaluates selected dice notation (e.g. `1d20+5`) in the active editor buffer. | `ctrl-alt-r` |
